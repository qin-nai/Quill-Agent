Quill Agent 项目结构 (2026-08-09)
Quill Agent/
│
├─ core/                                 Core 引擎 — 纯 C++ (C++17), 零平台依赖, 可开源
│  ├─ include/hermes/              引擎公开接口 (命名空间 hermes)
│  │  ├─ message.hpp                 消息模型 (Claude content block 结构)
│  │  ├─ agent_loop.hpp             Agent Loop (回合驱动 + 事件流)
│  │  ├─ http_transport.hpp         网络注入抽象 (WinHTTP/JNI 共用声明头)
│  │  ├─ provider.hpp               Provider 配置 + 12 家内置
│  │  ├─ skills.hpp                 Skills 扫描/解析 (SKILL.md frontmatter)
│  │  ├─ system_prompt.hpp          Agent.md 记忆 + 技能清单
│  │  ├─ task_runner.hpp            子代理 (thread_local, 嵌套 ≤3)
│  │  ├─ tool.hpp / tool_registry.hpp  工具协议 + 注册表
│  │  ├─ llm/                     适配器: Claude / OpenAI 兼容 / Stub
│  │  └─ tools/                   内置工具: read/write/edit/glob/grep/todo/task/run_script/web_fetch/web_search/read_skill
│  ├─ src/                        引擎实现 (agent_loop.cpp, llm/*.cpp, provider.cpp)
│  ├─ server/                     本地 HTTP server (cpp-httplib)
│  │  ├─ routes.cpp                 全部路由 (REST + SSE)
│  │  ├─ session_store / keystore / model_store  SQLite 持久化
│  │  ├─ run_context.cpp            回合共享状态 + SSE provider (15s 心跳)
│  │  ├─ tool_factory.cpp           工具装配 (内置 + 读 mcp_servers.json 注册 MCP)
│  │  ├─ mcp_client.cpp            MCP streamable HTTP 客户端 (JSON-RPC 2.0)
│  │  ├─ http_transport_winhttp.cpp Windows 网络层 (WinHTTP)
│  │  ├─ run_script_bridge.c       QuickJS 沙盒 C 桥 (C99, MSVC 降级 stub)
│  │  └─ platform_thread_windows.cpp 线程 enter/exit hook
│  ├─ cli/                        CLI 入口 (main.cpp)
│  ├─ third_party/                httplib / nlohmann_json / sqlite3 / quickjs (vendored)
│  ├─ tests/                     单元测试 (ctest)
│  └─ workspace/                  默认工作区 (Agent.md 项目记忆 + 示例)
│
├─ webui/                             原生 WebUI (vanilla JS, 零框架零依赖)
│  ├─ index.html / app.js / style.css
│  └─ DESIGN.md                     设计系统 (Quiet Pro) + UX 原则
│
├─ android/                          Android 打包 (WebView 壳 + JNI 桥)
│  ├─ README.md                      构建环境 + JNI 桥说明
│  ├─ server_android.cpp            JNI 入口启动本地 server
│  ├─ http_transport_android.cpp  JNI 桥 Java HttpURLConnection (系统 TLS)
│  ├─ platform_thread_android.cpp 线程 attach/detach hook
│  ├─ crash_handler.cpp / .hpp     native 崩溃处理
│  ├─ CMakeLists.txt / build.gradle  Gradle + NDK 30 工程
│  └─ app/src/main/               AndroidManifest + MainActivity + assets/webui + Java 桥
│     ├─ MainActivity.java          解压 webui → 后台起 server → WebView 加载
│     ├─ HermesHttp.java            HttpURLConnection JNI 桥
│     ├─ FileBridge.java            长按文件 → 用其他应用打开 (JS 桥)
│     ├─ WorkspaceFileProvider.java content:// 暴露工作区文件 (自实现, 严格限定工作区内)
│     └─ assets/webui/             内置 WebUI 副本
│
├─ docs/                             设计文档
│  ├─ Document.md                    架构设计文档
│  ├─ protocol.md                    HTTP/SSE 协议规范 (状态码 + 事件时序)
│  ├─ API.md                        HTTP API 手册 (REST + SSE 端点清单)
│  ├─ ENGINE_API.md                 Core 引擎接口明细
│  ├─ TROUBLESHOOTING.md            常见问题排查 (症状→原因→解决)
│  └─ DEV_LOG.md                    开发日志 (阶段演进)
│
└─ SVG/                             蓝图 / 架构图
   ├─ 项目结构骨架.html                           项目结构骨架 (当前文件)
   ├─ 引擎架构图.html                             分层架构 + 调用方向
   ├─ 引擎接口蓝图.html                           模块接口 + 调用关系
   └─ 前端接口蓝图.html                           WebUI ↔ REST/SSE
